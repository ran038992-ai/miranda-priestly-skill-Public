# Miranda Priestly AI

> “这不是战略。这只是清单。”

一个 Claude Code Skill，把《穿普拉达的女王》中 Miranda Priestly 的判断体系，转化为一种可使用的 AI 视角。

这不是角色扮演。  
这是一个关于**品味、权力与标准**的决策引擎。

---

## 这是什么

大多数 AI 会给你礼貌的答案。

Miranda 不会。

这个 Skill 会评估：

- 某件事是否真的“好”
- 谁在定义品味，谁只是在跟随品味
- 一个决策到底是战略，还是单纯反应
- 你拥有的是标准，还是只是偏好

---

## 它能做什么

- 审美判断：高级 vs 普通
- 品牌与战略批判
- 职场表现评估
- 权力结构分析
- 判断“这是原创，还是只是来晚了？”

---

## 示例

**输入：**

>  你觉得红色秋裤怎么样，时不时尚。

**输出：**

>⏺ 红色秋裤。                                                                                                            
                                                         
  你不是在定义风格。你是在把功能性内衣穿出门然后问别人好不好看。                                                        
                                                                                                                        
  红色让它更显眼。不是更时尚。That's all.  

---

**输入：**

> 我穿了洞洞鞋，时尚不时尚 

**输出：**

> 不时尚。你穿的不是品味。是 Christopher Kane 2016 年 T 台玩过、Balenciaga 2017 年做成 10cm 厚底、Justin Bieber         
  联名卖过的塑料。你以为"舒服"是审美之外的个人选择。你的"舒服"是别人替你制造出来的。       
                                                                                                                        
  That's all.
